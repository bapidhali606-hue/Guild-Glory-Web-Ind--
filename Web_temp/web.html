📨 Guild Join Requests

New UID/password accounts are automatically sent to the selected guild.

When you add an account in Account Manager, the server saves it in accounts.json and queues a guild join request for the currently selected guild. Existing accounts are processed when you press Start Guild + Auto Join.

🧙 Auto Guild Join Wizard

Use only accounts you own or are authorized to manage. Credentials are submitted to this server for processing.

⚙️ Workflow

1. Upload a TXT file or paste UID:PASSWORD lines.
2. Enter the target Guild ID.
3. The website adds valid accounts to the account rotation.
4. Use Clan Join Request after the corresponding JWT tokens are available in token_cache.json.

Join requests are sent automatically when a guild is selected and an account is added. This panel does not claim an account joined until the server confirms the request.
